# 打字机做成组件样式字段，而不是组件内容类型

r7 把逐字显示实现成一个自定义内容类型 `typewriter_text:typewriter`：用户必须把整段文字塞进 `type` 字段，因此永远无法和 `translate`、`score` 等原版内容类型组合，模组还要额外承担内容类型注册与网络判别编码。r8 改为在原版 `Style` 上增加一个可选的 `typewriter` 字段——文字完全走原版内容类型，凡是能写 `color`、`bold`、`clickEvent` 的位置都能写 `typewriter`，`extra` 嵌套与样式字段继承也照原版语义工作。

代价是一次**破坏性迁移**：r7 的 `{"type":"typewriter_text:typewriter",...}` 写法在 r8 不再解析。

## Considered Options

- **保留内容类型**：无法与 `translate`、`score` 等原版内容类型组合，正是用户提出要改掉的原因。
- **样式字段 + 兼容层（同时接受 r7 写法）**：会把刚删掉的内容类型注册与判别编码整套请回来，只换来"老写法不报错"。r7 从未对外发布，因此不划算，**不采用**。
- **样式字段并放弃 r7 写法（采用）**：迁移成本对用户就是改一次 JSON 结构（见 README 的 r7→r8 对照表）。
